- All services are available via the Frontend proxy: http://localhost:8080
  by running these commands:
     kubectl --namespace {{ .Release.Namespace }} port-forward svc/frontend-proxy 8080:8080

  The following services are available at these paths after the frontend-proxy service is exposed with port forwarding:
  Webstore             http://localhost:8080/
  Load Generator UI    http://localhost:8080/loadgen/
  Feature Flags UI     http://localhost:8080/feature/
  Telemetry Docs       http://localhost:8080/telemetry/

  This chart deploys the demo application and its own instrumentation agent
  only. Point the collector's otlp/observability-backend exporter at your
  platform's existing observability backend (see values.yaml, and
  examples/bring-your-own-observability for a worked example).
