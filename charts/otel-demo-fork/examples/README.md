# Examples of chart configuration

Here is a collection of common configurations for the demo. Each folder
contains an example `values.yaml` and the resulting configurations that are
generated by the otel-demo-fork helm chart.

- [Default configuration](default)
- [Bring your own Observability](bring-your-own-observability)
- [Custom Environment Variables](custom-environment-variables)
- [Disable Kubernetes Infrastructure Monitoring](disable-kubernetes-infra-monitoring)
- [Public Hosted HTTPRoute](public-hosted-httproute)
- [Kafka access via chart-managed Strimzi resources](kafka-access)
- [Kafka access via bring-your-own Strimzi resources](kafka-access-unmanaged)
- [Operator-managed collector (OpenTelemetryCollector CR)](operator-managed-collector)

The manifests are rendered using the `helm template` command and the specific
example folder's values.yaml.
